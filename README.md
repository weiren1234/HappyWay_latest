# HappyWay

HappyWay is a Flutter-based travel planning application designed for traveling in Malaysia. It combines destination discovery, weather forecasts, route estimation, and multi-stop itinerary management into a single seamless experience.

## Features

- **Destination Discovery**: Browse and search tourist destinations across Malaysia
- **Official Weather**: Daily weather forecasts from MET Malaysia
- **Hourly Weather**: Real-time hourly precipitation and temperature via Open-Meteo
- **Weather-Aware Planning**: Weather-based recommended arrival times to avoid rain
- **Multi-Stop Itinerary**: Plan multi-day trips with exact or flexible visit durations
- **Route Estimation**: Estimated driving distance, duration, and departure times via OSRM
- **Saved Places**: Bookmark favorite destinations for quick trip planning
- **User Accounts & Guest Mode**: Supabase-powered authentication with guest browsing support
- **Location Services**: GPS-based current location detection for nearby insights

## Technologies

- **Frontend**: Flutter / Dart, Provider
- **Backend & Auth**: Supabase
- **Weather APIs**: MET Malaysia API, Open-Meteo API
- **Routing & Maps**: OSRM, OpenStreetMap / Nominatim
- **Media**: Pexels API
